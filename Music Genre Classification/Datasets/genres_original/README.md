Such 100 recordings of length 30s of 10 different types of music genres: blues,classical,countries,discohiphop,jazz,metal,pop,reggae,rock constitute the dataset of this model. Due to its 
sheer size and issues with the repository, I have uploaded some of the '.wav' files as a representation of the dataset. The real dataset on which the model is trained on is the 'file.csv' 
CSV file which is present in the 'Datasets' directory and contains features of all these recordings/dataset.
